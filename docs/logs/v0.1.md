# P Trust v0.1 Implementation Log

Date: 2026-09-09

## Scope

Initial public research product: repository input, bounded public GitHub ingestion, seven analyzers, durable jobs, evidence reports and functional web UI. Private construction specifications remain outside this public repository.

## Decisions

- React/TypeScript + Worker + SQLite-backed Durable Objects keeps the product in one deployable Cloudflare application without a separate database service.
- Static detection first; no target execution, arbitrary URL fetches or personal GitHub tokens.
- Scores describe observed policy patterns; no fabricated safety guarantees or unsupported malware claims.
- AI output is restricted to existing finding IDs, disabled by default.
- Per-hour snapshots and quota limits are explicit to users.

## Verification

Typecheck, lint, 33 tests and seven-fixture benchmark passed. Six Playwright checks passed against the actual local Worker across 1440x1000 and 390x844 viewports: evidence expansion, JSON export, permissions, trajectory, coverage, modal Escape, no horizontal overflow, actual image rendering, seven fixture APIs and invalid-input boundaries. No page errors were observed. Deployment, CI and real public self-scan verification remain pending.

Dependency audit surfaced the transitive development dependency `sharp <0.35.4`. An explicit `sharp: 0.35.4` override applies the [upstream fix](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c), rather than downgrading Wrangler to an unrelated old release. The subsequent install audit reported zero vulnerabilities. Local Worker and browser tests passed with the override; CI will also verify Linux.

## Integration Corrections

The first actual GitHub self-scan failed at metadata ingestion because Workers rejects the Fetch `redirect: error` mode. The reader now uses `manual` plus an explicit 3xx rejection; a regression test verifies no follow-up request occurs. Failed jobs can be explicitly retried through the same rate-limited create endpoint, and operator diagnostics include a bounded error category/message.

The first Linux CI run passed typecheck, lint, 33 tests, benchmark, build and audit, but its local Worker startup attempted to establish a remote AI proxy despite interpretation being disabled. Development and CI now pass Wrangler's documented `--local` option to disable remote bindings. No Cloudflare account secret is required by CI.
